# 简笔画生成器

将普通照片转化为简笔画风格的线稿图，通过边缘检测算法自动提取轮廓线条。

## 使用步骤

1. **上传图片** — 点击上传按钮或拖拽图片到页面
2. **调节参数**
   - **边缘阈值** — 数值越大，保留的线条越少（越简洁）；越小，线条越丰富（越细腻）
   - **模糊程度** — 数值越大，线条越平滑；越小，细节越多
3. **实时预览** — 参数调整后自动刷新预览效果
4. **下载图片** — 满意后点击「下载」保存简笔画图片

## 注意事项

- 建议使用轮廓清晰、背景简洁的图片效果更佳
- 图片越大处理时间越长，推荐宽度不超过 2000px
- 全程本地处理，图片不会上传至服务器
