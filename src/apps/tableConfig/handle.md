# 表单引擎

可视化低代码工具，通过 JSON 配置快速生成增删改查页面，支持实时预览和导出完整 React 项目源码。

## 使用步骤

### 第一步：配置页面
1. 打开「配置器」Tab
2. 填写页面标题
3. 添加**搜索条件**：选择组件类型（输入框 / 下拉 / 日期等），填写字段名和标签
4. 添加**表格列**：配置列标题、字段名、列宽等属性
5. 配置**操作按钮**：开启新增、编辑、删除等操作

### 第二步：预览效果
- 点击「预览」Tab，即可看到根据配置实时渲染的完整页面效果

### 第三步：导出源码
- 点击「导出源码」，下载完整的 React 项目压缩包
- 解压后包含组件、Service 层、样式文件，可直接集成到项目中

## 支持的组件类型

`input` · `select` · `datePicker` · `rangePicker` · `treeSelect` · `inputNumber` · `switch` 等共 22 种

## 注意事项

- 配置数据仅保存在当前页面，导出源码前请勿刷新
- 导出的代码基于 React + Ant Design 5.x，请确保项目依赖版本匹配
