# 学习笔记

在线笔记管理工具，支持创建、编辑和整理技术学习笔记，结合 Markdown 格式让内容排版更清晰。

## 使用步骤

1. **新建笔记** — 点击「新建」按钮，输入笔记标题
2. **编写内容** — 在编辑区使用 Markdown 语法编写笔记正文
3. **保存笔记** — 点击「保存」或使用快捷键 `Ctrl/Cmd + S` 保存
4. **管理笔记** — 在左侧列表中查看、搜索、切换笔记
5. **删除笔记** — 选中笔记后点击「删除」，确认后移除

## 注意事项

- 笔记数据保存在本地或账号中，登录后可跨设备同步
- 支持 Markdown 语法，可搭配「Markdown 编辑查看器」预览效果
