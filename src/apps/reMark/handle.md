### Markdown 编辑查看器

所见即所得的在线 Markdown 编辑器，左侧编辑、右侧实时渲染，快速撰写与预览 Markdown 文档。

#### 使用步骤

1. **输入内容** — 在左侧编辑区输入 Markdown 语法内容
2. **实时预览** — 右侧自动渲染格式化效果，边写边看

#### 支持的语法

| 语法 | 示例 |
|------|------|
| 标题 | `# H1`  `## H2` |
| 粗体 / 斜体 | `**粗体**`  `*斜体*` |
| 代码块 | ` ```js ... ``` ` |
| 表格 | `\| 列1 \| 列2 \|` |
| 图片 / 链接 | `![alt](url)`  `[text](url)` |

```plaintext
# 仅作注释使用
> [!note]
> 注释文字

# 重要的提示
> [!important]
> 重要文字

# 简单的提醒
> [!tip]
> 提示文字

# 特别注意
> [!warning]
> 注意文字

# 重大风险、利好或重大影响
> [!caution]
> 警告文字
```

#### 注意事项

- 内容仅保存在浏览器本地，刷新前请及时导出
- 支持拖拽 `.md` 文件到编辑区直接打开
