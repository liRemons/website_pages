# 简易 Markdown

在线 Markdown 编辑器，左侧输入内容、右侧实时预览，支持打印导出 PDF。

## 使用步骤

1. **编辑内容** — 在左侧编辑器输入 Markdown 文本，右侧即时渲染预览
2. **拖拽调整** — 拖拽中间分割条可调整左右面板比例（移动端为上下布局，拖拽调整高度）
3. **打印导出** — 点击右上角「打印」按钮可将当前预览内容发送至服务端生成 HTML/PDF
4. **帮助** — 点击右上角帮助图标可查看本说明

## 支持的语法

标题、加粗、斜体、列表、表格、代码块、图片、链接、引用、分割线等标准 Markdown 语法，以及 Mermaid 图表渲染。

## 注意事项

- 拖拽面板比例限制在 20%~80% 之间
- 移动端自动切换为上下布局
- 打印功能依赖服务端接口
