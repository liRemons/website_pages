# 解析二维码

接收端工具，用于解码「生成二维码」页面产生的系列二维码，还原原始数据内容。无需网络、蓝牙或局域网。

## 使用步骤

1. **打开页面** — 在接收设备上打开本页面
2. **逐张扫描** — 使用设备摄像头依次扫描发送端展示的二维码（顺序不限）
3. **查看进度** — 页面实时显示已扫 / 总数进度条
4. **补缺（可选）** — 若剩余不足 10 张时，可手动输入缺失序号进行补全
5. **获取数据** — 全部扫描完成后，自动还原并展示原始内容，支持复制或下载

## 注意事项

- 本工具需配合「生成二维码」页面使用
- 全程离线可用，适合无网络 / 禁用蓝牙和局域网的场景
- 同一批二维码请勿混入其他批次的图片
