# 富文本编辑器

基于 wangEditor 的在线富文本编辑器，所见即所得地编辑图文内容，支持导出标准 HTML 代码。

## 使用步骤

1. **编写内容** — 在编辑区直接输入文字，使用工具栏设置格式
2. **格式操作**
   - 标题 / 正文 / 引用：工具栏左侧下拉选择
   - 粗体 / 斜体 / 下划线：选中文字后点击对应按钮
   - 插入图片：点击图片图标，上传或粘贴图片 URL
   - 插入表格：点击表格图标，选择行列数
3. **查看 HTML** — 点击「源码」按钮查看或直接编辑 HTML 代码
4. **复制 / 导出** — 复制 HTML 源码用于网页或后台富文本字段提交

## 注意事项

- 内容仅保存在当前页面，刷新前请及时复制保存
- 粘贴外部内容时会自动清理多余格式，保持排版整洁
