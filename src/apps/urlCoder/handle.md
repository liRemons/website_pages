# URL 转编码

将 URL 参数快速拆解为 Key-Value 可视化表格，支持编码与解码互转，开发调试必备工具。

## 使用步骤

1. **粘贴 URL** — 将完整的 URL 或 Query String 粘贴到输入框
2. **解析参数** — 点击「解析」，自动拆分所有参数为表格展示
3. **查看 / 编辑** — 在表格中直接查看或修改每个参数的 key 和 value
4. **编码转换** — 对需要编解码的参数值，点击对应行的「编码 / 解码」按钮
5. **复制结果** — 修改完成后复制重新组合的 URL 或单个参数值

## 注意事项

- 支持完整 URL（含域名）和纯 Query String（`?key=value&...`）两种输入格式
- 中文、特殊字符会自动进行 `encodeURIComponent` 处理
