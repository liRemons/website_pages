# 邮戳生成器

在线复古邮戳印章生成器，自定义地点、日期、颜色和样式，实时预览并下载高清邮戳图片。

## 使用步骤

1. **填写内容**
   - 输入地点名称（如：黄山、北京）
   - 选择日期（默认为当天）
2. **自定义样式**
   - 选择印章颜色（支持任意颜色拾取）
   - 选择邮戳风格（经典 / 现代等）
   - 调整印章尺寸和旋转角度
3. **设置字体**
   - 从内置字体中选择，或点击「加载本地字体」使用系统字体
4. **实时预览** — 所有修改即时更新到预览区
5. **下载图片** — 点击「下载」保存高清邮戳 PNG 图片

## 注意事项

- 「加载本地字体」需要 Chrome 103+ 并授权字体访问权限
- 下载图片为透明背景 PNG，可直接叠加到其他设计中使用
