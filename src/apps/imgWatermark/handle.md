# 图片水印

为图片添加文字或图片水印，保护原创版权，防止图片被盗用。

## 使用步骤

1. **上传图片** — 点击上传区域或拖拽图片文件到页面
2. **选择水印类型** — 文字水印 / 图片水印
3. **配置水印样式**
   - 文字水印：输入水印文字，调整字体大小、颜色、透明度
   - 图片水印：上传水印图片，调整大小与透明度
4. **调整位置** — 选择水印位置（左上 / 居中 / 右下等）或拖拽自由定位
5. **下载图片** — 点击「下载」保存带水印的图片

## 注意事项

- 支持 JPG、PNG、WebP 等常见图片格式
- 全程本地处理，图片不会上传至服务器，安全放心
