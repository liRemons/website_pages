# Mermaid 图表

在线 Mermaid 图表实时渲染工具，左侧编辑源码、右侧即时预览，支持多种图表类型。

## 使用步骤

1. **编辑源码** — 在左侧编辑器输入 Mermaid 源码（带行号），右侧自动实时渲染（输入后约 300ms 生效）
2. **插入模板** — 点击「插入模板」可快速加载流程图、时序图、类图、状态图、甘特图、饼图、ER 图、用户旅程图等示例
3. **缩放查看** — 使用预览区工具栏的放大 / 缩小 / 重置按钮，或在预览区上滚动鼠标滚轮缩放，拖拽平移
4. **全屏** — 点击全屏按钮进入全屏模式浏览大图，再次点击或按 Esc 退出
5. **下载** — 点击「下载」可将当前图表导出为 SVG 或 PNG（PNG 为 2 倍清晰度）
6. **主题切换** — 右上角选择默认 / 暗色 / 森林 / 中性 主题

## 支持的图表类型

`flowchart`（流程图）、`sequenceDiagram`（时序图）、`classDiagram`（类图）、`stateDiagram-v2`（状态图）、`gantt`（甘特图）、`pie`（饼图）、`erDiagram`（ER 图）、`journey`（用户旅程图）等 Mermaid 官方支持的语法。

## 注意事项

- 源码语法错误时，预览区顶部会显示红色错误提示，修正后自动恢复渲染
- 主题切换会重新渲染图表
- 移动端自动切换为上下布局
