# JSON 解析器

在线 JSON 解析与可视化工具，支持格式化、压缩、层级折叠与复制操作。

## 使用步骤

1. **输入 JSON** — 在左侧文本框粘贴或输入 JSON 内容，右侧实时解析展示
2. **格式化** — 点击「格式化」按钮，将压缩的 JSON 整理为缩进格式
3. **压缩** — 点击「压缩」按钮，移除空白字符，生成最小体积 JSON
4. **折叠/展开** — 点击右侧「折叠全部」收起所有层级，点击节点前的箭头展开
5. **复制** — 点击「复制」按钮复制当前输入框内容到剪贴板

## 注意事项

- 输入内容变化时自动解析，错误提示会显示在输入框底部
- 右侧每个节点均可单独点击折叠/展开，也支持一键折叠全部
