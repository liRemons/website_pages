# 生成二维码

将文本、网址或文件内容编码成一组二维码图片，配合「解析二维码」工具完成无网络环境下的数据传输。

## 使用步骤

1. **输入内容** — 在输入框中粘贴或输入要传递的文本 / URL
2. **生成二维码** — 点击「生成」，系统自动将内容拆分为多张二维码（单次最大 200 KB）
3. **展示扫描** — 将生成的二维码逐张展示给接收端，使用「解析二维码」页面扫描
4. **补缺处理** — 若接收端提示缺少某张，可手动输入序号进行补缺

## 注意事项

- 单次传输上限为 **200 KB**，超大内容请压缩后再传
- 扫码顺序无严格要求，但建议按序扫描提升效率
- 全程无需网络、蓝牙或局域网连接
